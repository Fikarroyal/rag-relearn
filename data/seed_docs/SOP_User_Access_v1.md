# SOP User Access v1

## Bagian 1: Tujuan
SOP ini mengatur pemberian, perubahan, dan pencabutan hak akses pengguna sistem informasi.

## Bagian 2: Prosedur Pembuatan Akses Pengguna Baru
Pembuatan akses pengguna baru: 1. Atasan mengajukan formulir akses. 2. Kepala IT menyetujui. 3. Administrator membuat akun dengan prinsip least privilege. 4. Pengguna mengganti password pertama kali.

## Bagian 3: Review Akses
Review hak akses seluruh pengguna dilakukan setiap 6 bulan oleh Kepala IT.

## Bagian 4: Pencabutan Akses
Akses pengguna yang resign dicabut maksimal 1 hari kerja setelah tanggal efektif.
